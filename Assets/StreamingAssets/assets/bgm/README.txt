BGM フォルダの使い方
====================
(Unity 版では、このフォルダは Assets/StreamingAssets/assets/bgm にある。
 data/bgm.csv は Assets/StreamingAssets/data/bgm.csv)

■ フォルダの構成
  bgm/
    Title/     タイトル画面で流す曲
    Menu/      メニュー画面で流す曲
    Battle/    バトル画面で流す曲

■ 曲の入れ方
  ・流したい画面のフォルダに、音楽ファイルを1つ入れる(ファイル名は何でもよい)
  ・その画面に切りかわったときに流れて、くり返し再生される
  ・フォルダに曲がなければ、その画面では音楽が止まる
  ・曲がいくつも入っているときは、名前順で最初の曲を流す
  ・タイトルとメニューに同じ曲を入れると、画面を行き来しても曲は止まらずに流れつづける
  ・各フォルダにある「ここに音楽を入れる.txt」は消してもかまわない(音楽以外のファイルや、Unity が作る .meta は無視する)

■ 使えるファイル
  .ogg  .mp3  .wav  (.aif .aiff)
  (いちばん確実なのは .ogg か .mp3。Unity 版では .flac と .opus は流せない)

■ 音量
  data/bgm.csv の「音量」(0〜100)で、画面ごとに変えられる

■ 曲や音量を変えたとき
  ゲームを起動したままでも、タイトルで「はじめる」を押すと、音量の表と曲を読みなおす
  (曲は、その画面に入りなおしたときに入れかわる)
